# Publication and portfolio plan

## Immediate state

Private GitHub project; owner-reviewed README/report; manuscript draft. No submission, peer review or prospective validation is claimed. The project can be listed now under Projects/Research Software; a draft is not a publication entry.

Suggested project bullet:

> Built a provenance-preserving protein–ligand ranking benchmark over 3.23 million curated BindingDB activity records, using chiral molecular fingerprints and ESM-2; implemented historical snapshot matching, leakage controls and reproducible model evaluation.

Suggested result bullet:

> Compared a dual encoder with simpler baselines on 22,221 new-to-fitting pairs; preserved a negative architecture comparison (macro AUROC 0.781 versus 0.789) and a separately failed docking gate rather than tuning to a desired result.

These describe the project. Be ready to explain AI-assisted development and the code/analyses you personally understand. Do not present assistants as human authors or assume sole authorship if other humans contributed.

## Manuscript sequence

1. Review the draft for methods accuracy, scope, author contributions and affiliation.
2. Review primary related work and make the contribution comparative, not a first-ever claim.
3. Add two figures from recorded artifacts: cohort flow and per-target model comparison. New uncertainty analysis, if desired, must be explicitly post-hoc and must not silently replace original results.
4. Agree code/data/model distribution terms, publish an immutable software version, and make reproduction work from its documented artifact scope.
5. Release a dated technical report/preprint with a persistent identifier when ready. A ResearchGate or LinkedIn upload is distribution, not peer review. A DOI identifies a release; it does not certify scientific quality.
6. Resume categories should match state: Project now; Manuscript in preparation if genuinely preparing it; Preprint only after a dated public preprint; Peer-reviewed publication only after acceptance/publication.

The best paper framing is a reproducible benchmark/case study with negative results. A short draft is enough for understanding; a formal methods paper would need more comparative positioning and possibly broader experiments. Neither new training nor experimental success is required to document the work honestly.
